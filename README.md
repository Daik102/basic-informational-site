<h1>Project: Basic Informational Site</h1>

A Node.js HTTP server project with several features<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Using native Node.js core modules (http, fs, path, url) without frameworks

- Multi-page views (/, /about, /contact-me)

- Error Management (a custom 404 Not Found error page, and 500 Internal Server Errors)

<h3>Tech Stack</h3>

- Frontend: HTML, CSS

- Backend: Node.js
