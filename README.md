<h1>Project: Basic Informational Site</h1>

A multi-page web app with several features<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Using Express for clean HTTP handling

- Multi-page navigation (/, /about, /contact-me)

- Error Management (a custom 404 Not Found error page)

<h3>Tech Stack</h3>

- Frontend: HTML, CSS

- Backend: Node.js, Express
